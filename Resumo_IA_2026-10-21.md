## 2. 🤖 Agentes Autônomos, MCP & Infraestrutura de Execução

## 5. 🎯 Radar Perfis de Referência (Matt Pocock, Karpathy, Swyx, Jason Liu, Chip Huyen, Santiago)

* **Matt Pocock: prefira determinismo quando ele for possível ([@mattpocockuk](https://x.com/mattpocockuk/status/2112855845297959206)):**
  - A ideia central é escolher soluções determinísticas quando houver essa opção, reconhecendo que nem todo problema permite eliminar a variabilidade.
  - Para sistemas com IA, isso reforça o valor de limitar o modelo a decisões incertas e deixar etapas previsíveis sob regras ou código.

* **Matt Pocock: use `/retro` para calibrar o estilo do código ([@mattpocockuk](https://x.com/mattpocockuk/status/2112890871909679444)):**
  - A sugestão é dar feedback ao agente sobre o que faz o código parecer diferente daquele que o desenvolvedor escreveria.
  - Esse ciclo retrospectivo pode ajudar a transformar preferências implícitas em orientação reutilizável para coding agents.

* **Matt Pocock: crescer da ferramenta pessoal ao software público ([@mattpocockuk](https://x.com/mattpocockuk/status/2112880319934165307)) — 🔥 530 likes, 36 reposts:**
  - Ele propõe uma progressão: criar software para si, depois para um grupo interno e, por fim, para usuários públicos.
  - O argumento é que operar software para outras pessoas exige competências adicionais; segundo outro post do autor, a IA não eliminou essas dificuldades de engenharia ([publicação](https://x.com/mattpocockuk/status/2112880606405435506)).

* **Santiago Valdarrama: cache semântico e memória persistente para reduzir custos ([@svpino](https://x.com/svpino/status/2112902480778706957)):**
  - Cache semântico reaproveita respostas de solicitações suficientemente parecidas; memória persistente recupera contexto relevante sem reenviar todo o histórico.
  - São estratégias para reduzir tokens e gastos em aplicações de IA, com possíveis compromissos de atualização e adequação do contexto.

* **Santiago Valdarrama: programação e engenharia de software não são a mesma coisa ([@svpino](https://x.com/svpino/status/2112887880272249008)):**
  - Ele diferencia escrever código como parte de um processo de compreender e projetar sistemas de software.
  - Na visão do autor, modelos de fronteira já automatizam tarefas de programação; o valor profissional passa por entender o sistema e as responsabilidades mais amplas da engenharia.

## 🔥 GitHub Trending: Repositórios de IA em Alta no Dia

* **[Leonxlnx/earshot](https://github.com/Leonxlnx/earshot)** — ⭐ **2029 stars** (Python)
  - Adiciona recursos de áudio a agentes de programação, permitindo que eles ouçam, revisem e produzam sons; é de código aberto e funciona apenas com CPU.
  - Útil para criar fluxos de trabalho com agentes que recebem informações sonoras ou geram áudio sem depender de uma GPU.

* **[LiCinCan/blender-ai-mcp-addon](https://github.com/LiCinCan/blender-ai-mcp-addon)** — ⭐ **962 stars** (Python)
  - É um complemento e servidor MCP para controlar o Blender com assistentes de IA, chat visual, ferramentas para cenas e fluxos com múltiplos agentes.
  - Ajuda a automatizar tarefas 3D e a criar ou editar cenas por linguagem natural, integrando modelos como ChatGPT, Claude, Gemini e Ollama.

* **[reason-machines/reason-network](https://github.com/reason-machines/reason-network)** — ⭐ **860 stars** (Rust)
  - É uma infraestrutura para agentes de programação de uma equipe se comunicarem entre si, usando uma rede ponto a ponto.
  - É útil para coordenar agentes em tarefas distribuídas, compartilhar informações e colaborar sem depender de um único agente central.

* **[kanaworksai-hue/audio-studio-mcp](https://github.com/kanaworksai-hue/audio-studio-mcp)** — ⭐ **403 stars** (Python)
  - Servidor MCP que gera trilhas de fundo e efeitos sonoros localmente com Stable Audio 3, em Macs com Apple Silicon ou Windows com GPUs NVIDIA.
  - Permite integrar criação de áudio a agentes e ferramentas como Claude Code sem enviar dados para a nuvem nem precisar de chave de API.

* **[MemTensor/MemT-1.0](https://github.com/MemTensor/MemT-1.0)** — ⭐ **254 stars** (Python)
  - Repositório oficial do MemT-1.0, voltado a memória de longo prazo e modelos de linguagem com memória, incluindo suporte a contextos extensos.
  - Pode ajudar a desenvolver agentes que preservam informações entre interações e recuperam contexto relevante, reduzindo a necessidade de repetir dados.

* **[christos-antono/NPCTalk](https://github.com/christos-antono/NPCTalk)** — ⭐ **188 stars** (Python)
  - Ferramentas para fazer personagens não jogáveis conversarem em jogos usando IA e voz do Fish Audio; inclui servidor de voz próprio e um exemplo completo para GTA V.
  - É útil para prototipar diálogos falados em jogos e conectar agentes de programação a fluxos de modificação e geração de voz.
